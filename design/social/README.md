# Logos de redes

SVG originales importados en Assets.xcassets/Social*.imageset. Se renderizan como template monocromo blanco o negro según el colorScheme; no se altera su geometría. Perfiles configurados: GitHub AnubisReal, Instagram @anubisreal y X @Anubisreal23.

Fuentes oficiales:
- GitHub: https://brand.github.com/foundations/logo — GitHub_Logos.zip, GitHub_Invertocat_Black.svg.
- Instagram: https://www.meta.com/brand/resources/instagram/instagram-brand/ — IG_brand_asset_pack_2023.zip, Instagram_Glyph_Black.svg.
- X: https://about.x.com/es/who-we-are/brand-toolkit — https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-logo.zip.

Marcas propiedad de sus respectivos titulares. Se usan para identificar los perfiles sociales, sin implicar afiliación.
